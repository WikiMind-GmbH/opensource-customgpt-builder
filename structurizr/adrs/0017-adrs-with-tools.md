# 17. ADRs with tools

Date: 2025-11-19

## Status

Accepted

Supercedes [1. Record architecture decisions](0001-record-architecture-decisions.md)

## Context

We want to streamline working with adrs. 
Using the command line tools lets us quickly create adr templates with the correct file name and header, as well as giving the possibility to automatically edit superseded adrs. 
A widely adopted tool is [ADR Tools](https://github.com/npryce/adr-tools) that 

## Decision

We will use [ADR Tools](https://github.com/npryce/adr-tools) from now on.

## Consequences

Adding the tutorial for this tool must be considered.
We will always use this tool in this project. If it works well, we might implement this in all projects.
